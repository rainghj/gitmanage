## tauri dev 死灰复燃坑（当场处理）

- 触发条件：用户在截图里看到应用窗口是 Edge 的"ERR_CONNECTION_REFUSED / localhost 拒绝连接"。
- 根因：Rust 重编译完成后 `tauri dev` 主进程没有正确派生 `pnpm dev` (vite) 的重启，vite 进程异常退出但 tauri 主进程还活着，WebView 指向死地址。
- 排查方法：
  1. `curl -s -o /dev/null -w "%{http_code}" http://localhost:1420` → 看是 200 还是 502/无响应
  2. `tasklist` 看 node.exe 是否存在
  3. Git Bash 的 `</dev/tcp/127.0.0.1/1420` 在 Windows 下不准（会显示 CLOSED），**以 curl 为准**
- 恢复方案：杀干净重启——
  ```bash
  # Git Bash 下（注意用 cmd 转发，taskkill 的 // 会报错）
  cmd //c "taskkill /F /IM gitmanage.exe & taskkill /F /IM node.exe"
  # 或者 PowerShell：
  #   Get-Process gitmanage,node | Stop-Process -Force
  sleep 2 && pnpm tauri dev  # 后台跑
  ```
- 经验：以后长时间 dev 中如果窗口变 ERR_CONNECTION_REFUSED，几乎都是这个原因。

## 第七轮：远程操作（fetch / pull / push）

- 选型：git2 默认关闭了 https/ssh，所以走 **git CLI 侧车**（std::process::Command）
- 优势：复用 Windows 凭据管理器 + SSH agent + 已装的 git，不引入 openssl-sys 重型依赖
- Rust：`git_remote_op(op, remote: Option, branch: Option) -> Result<String, String>`
  - op ∈ {"fetch","pull","push"}，默认 remote="origin"
  - 关键环境变量 `GIT_TERMINAL_PROMPT=0` —— 防止 git 在后台弹交互式凭据输入把界面卡死
  - 检测 Authentication failed / Permission denied 等关键字时给出"凭据未提供"提示，引导用户用 Windows 凭据管理器或 SSH
  - 合并 stdout + stderr 一起返回（git 的进度信息走 stderr）
- 前端：
  - 顶部右侧加按钮组 `↓ fetch / ↓ pull / ↑ push / ▲ Console`，调用自动展开面板
  - 底部可折叠 Console 面板（200px 高，黑底 monospace），fetch/pull/push 输出的原始 git 输出都在这里
  - 操作期间按钮禁用并显示 …
  - 成功后自动 refresh() 拉新分支和提交

## 第八轮：Stash 操作

- 选型：本地操作，直接用 git2 原生 stash API（stash_save / stash_foreach / stash_apply / stash_pop / stash_drop），比启 CLI 进程更快。
- Rust：
  - 5 个命令：stash_list / stash_save / stash_apply / stash_pop / stash_drop
  - stash_save 用 StashFlags::INCLUDE_UNTRACKED（包含新增未跟踪文件）
  - signature_or_default 兜底：仓库没配 user.name/email 时用 `GitManage <gitmanage@local>` 顶替，避免直接报错
- **踩坑**：git2 的 stash_* API 需要 `&mut Repository`，但之前 `with_repo!` 宏给的是 `&`。修法：宏统一改为 `as_mut()` 拿 `&mut Repository`——不可变 API 接受 `&mut` 会自动 reborrow 为 `&`，统一可变更省心
- 前端：
  - 状态栏 Stash 区块（左栏底部）：每项三按钮（apply / pop / drop），全 confirm 防误删
  - 提交框多一个 "Stash 暂存" 按钮（仅在工作区有改动时出现）
  - refresh() 同时拉 stash_list
- 编译又走稳态三步：kill → cargo build（2m25s）→ pnpm tauri dev
