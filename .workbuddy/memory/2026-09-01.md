## 第三轮：文件夹选择对话框

- 需求："打开仓库"改为可弹出系统文件夹选择器自选目录。
- 方案：tauri-plugin-dialog v2（官方插件）。三处必需改动：
  1. 前端 `pnpm add @tauri-apps/plugin-dialog`，`import { open } from "@tauri-apps/plugin-dialog"`
  2. Rust Cargo.toml 加 `tauri-plugin-dialog = "2"` + lib.rs `.plugin(tauri_plugin_dialog::init())`
  3. **capabilities/default.json 的 permissions 必须加 "dialog:default"**（插件默认权限不在 core:default 里，漏了会运行时报错）
- `open({ directory: true, multiple: false, defaultPath })` 返回 string|null，取消时为 null。
- 验证：exe 17:54:20 重编（15.6MB→16.4MB），新进程内存 31.9MB。
- 校验编译完成的方法：看 target/debug/gitmanage.exe 时间戳是否晚于源码，以及 rustc/link.exe 是否归零。

## 第四轮：分支图 lane 连线 + discover 容错

- open_repo 改用 `Repository::discover(path)` 向上逐级查找 .git（选中仓库子目录也能打开），失败回退 `Repository::open`，再失败才报中文错误；返回真实仓库根（trim 结尾分隔符），前端回填输入框。
- 分支图：**纯前端计算**（不改 Rust，用已有的 parents 数组），在 App.tsx 里 computeGraph 维护 lanes 泳道数组：
  - commit 已在某泳道则沿用，否则占空泳道/新开
  - 第一父接手当前泳道；merge 的第二父另开泳道 → 产生分叉/汇合
  - 每行快照 occupied 画竖线，merge 行画贝塞尔汇合曲线，节点画圆点
  - 泳道配色用 VS Code 色板（无紫色）：#569cd6 #4ec9b0 #d7ba7d #ce9178 #b5cea8 #9cdcfe
- 关键耦合：SVG 行高 GRAPH_ROW_H(46) 必须与 CSS .commit-item 的 height(46px) 一致，否则竖线接不上。
