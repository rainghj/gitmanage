# 2026-09-01

## gitmanage 项目启动

- 目标：做一个类似 IDEA Git Tool Window 的轻量 Git 管理器，占用系统资源少，仅面向 Windows 11。
- 技术选型（已确认）：Tauri v2 + React/TS + git2-rs（libgit2，default-features=false 关闭 ssh/https/openssl，v0.1 只做本地仓库操作；远程推拉后续用 git CLI 侧车）。
- 布局：对齐 IDEA 截图——顶部仓库栏 + 左侧文件树/工作区更改 + 中间分支行+提交历史 + 右侧改动文件+diff。VS Code 风格深色蓝灰调。

## 首轮收尾（同日）

- Rust 编译修过 4 个错：head 借用阻止 repo move（块作用域解决）、upstream Option<&str>→Option<String>、commit_diff 缺生命周期参数、git2 0.20 的 Diff::print 回调 delta 是 DiffDelta 而非 Option。
